## 3. P1a 晋级证据阶梯（核心设计）

**原则：评测事件从专属题池抽未用过的题；练习事件（关卡/巩固）永不消耗评测池。** 每级用该间隔下最诚实（猜测底噪最低）且孩子没见过的信号：

| 晋级点 | 现状 | 改为 | 素材 | 预期 |
|---|---|---|---|---|
| stage-1→2（D+2） | d5 cloze MCQ（53.4%，噪声） | **d2 zh_word MCQ**（fresh，池 2 题/词） | 已有 | ≈87%（zh_word 实测基线），晋级恢复信号 |
| stage-2→3（D+7） | d5 随机（cloze/zh_word 混） | **d5 cloze MCQ 独占 fresh**（P0 后 D+0 不再消耗；238 缺 cloze 词降级 d5 zh_word） | 已有 | 未知，这才是 cloze 的真实测量值，上线后观测 |
| stage-3→mastered（D+19） | d12 随机 MCQ | **d12 spell 自由拼写**（0% 猜测底噪；前端拼写格/自动播音/复习路径全部现成，`spellSubmit→afterReviewAnswer` 已支持复习态拼写） | 已有（2447 词全覆盖） | 会变难（L4 关卡拼写首答 72.8% 且是刚学完），由 P1b 缓冲 |
| junior | 不变（JUNIOR_TYPES 无 cloze/spell，再认管线） | 不变 | — | Mido 1A，一年级不引入拼写产出 |

# scheduler.py get_today_queue 复习循环替换（stage1-cloze 分支删除）

## 4. P0 / P1b / P2a / P2b / 文档

**P0 用词关去 cloze**（`_new_word_item`）——d5 仅有的 1 道 cloze 留给 stage-2 评测独占：

```python
# 用词关（v3.2）：只借 d5 zh_word（mark_used=False 不耗配额）。不再借 cloze——
# 每词仅 1 道 cloze 保留给 stage-2(D+7) 评测（旧实现 D+0/D+2 100% 同题污染判据）。
# 无 d5 zh_word 的词该关自动跳过（buildQueue 对 reinforce=None 已兼容）。
item["reinforce"] = (
    None if junior else _quiz_by_type(db, r["id"], "d5", "zh_word", user_id, mark_used=False))
```

代价：D+0 用词关从"语境组词"暂时退化为"义→形回想"（这是本方案唯一的体验降级）。后续内容管线可为用词关生成专属语境题恢复，见 §7。

**P1b 部分重置**（`submit_answer` 答错分支）：

```python
old = row["stage"]
# stage-3 失败降一级回 stage-2（防 31 天完整回炉）；stage-1/2 失败回 1；
# audit 失败仍满重置——长间隔后的遗忘是强证据，与 D+19 轨迹内失败性质不同
new_stage = 1 if (phase == "audit" or old <= 2) else 2
```

现有 266 词无 stage≥2 的答错历史受影响（规则只作用于未来的答错事件）。

**P2a 听写关末支架式重测**（前端，`gateRetry` + 模板）：spell 关的重测项加 `_scaffold: true`；进入先自动播音 + 完整展示正确拼写（字母高亮，3s），按钮"记住了，重新默写"→ 清空进入正常拼写格。数据流不变（postQuizLog retry 标记照旧）。解决 L4 重测 37.4% 的"看完原题重拼还是不会"。

**P2b 新卡乱序呈现**（前端 `buildQueue`）：`today.new` 洗牌后仅用于呈现顺序（`_i` 为显示序），后端按 plan seq 分配的逻辑不变；learnedToday / 关卡 / 热身不受影响。消除库模式同单元词（Monday…Sunday 同日）的语义聚类干扰（Tinkham/Waring 经典结论：近似词同日编码互扰）。

**文档**：README "REVIEW_CAP=40"→60；scheduler.py:729 "波次交错"旧注释改为"整块顺序（热身→新词→复习→关卡），关内独立乱序"。

## 5. 已接受的残余影响（不修，记录在案）

1. **当前 266 词的历史 D+0 cloze 曝光无标记**：它们的 stage-2 评测（D+7，≥7 天间隔）可能重见 D+0 那道 cloze 一次。7 天间隔在同题复用上符合系统既有标准（"间隔≥3 天重复出题可接受"），且修复该残余需要回填写库，违反红线优先级。新学词完全干净。
2. reinforce 降级为义→形（§4 已述）。
3. 跨日界两次构建导致的单日复习>60（11-08 的 68）：非缺陷，不修。
